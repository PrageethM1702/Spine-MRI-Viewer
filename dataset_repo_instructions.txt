DATASET AND GIT-ANNEX INSTRUCTIONS
==================================

Repository:
   https://github.com/spine-generic/data-multi-subject

This app uses the spine-generic multi-subject dataset. The repository metadata
is small, but MRI and derivative NIfTI files are managed with git-annex and are
downloaded on demand.

------------------------------------------------------------
DATA FOLDERS
------------------------------------------------------------

The app creates these folders automatically:

   data/data-multi-subject/
   data/cache/
   data/metrics/

Do not commit these folders to GitHub. They are intentionally ignored by
.gitignore because they may contain large NIfTI files, cache files, and uploaded
metric tables.

------------------------------------------------------------
WHAT IS DOWNLOADED AUTOMATICALLY
------------------------------------------------------------

During Codespaces/devcontainer setup:

   data/data-multi-subject/participants.tsv

During app use:

   Subject T2w MRI files are fetched when the user clicks Download.
   Spinal cord segmentation and label derivatives are fetched when overlays are needed.
   PAM50 files are fetched when required by the overlay pipeline.

Metric CSV/TSV files are not part of this project by default. They must be
uploaded by the client through the app or placed manually in:

   data/metrics/

------------------------------------------------------------
MANUAL DATASET SETUP, IF NEEDED
------------------------------------------------------------

From the project root:

   mkdir -p data
   git clone https://github.com/spine-generic/data-multi-subject data/data-multi-subject
   cd data/data-multi-subject
   git annex init
   git annex enableremote computecanada-public

To fetch one subject MRI manually:

   git annex get sub-XXX/anat/sub-XXX_T2w.nii.gz

To fetch subject overlay derivatives manually:

   git annex get derivatives/labels/sub-XXX/anat
   git annex get derivatives/labels_softseg/sub-XXX/anat
   git annex get derivatives/labels_softseg_bin/sub-XXX/anat

Replace sub-XXX with the actual subject ID.

------------------------------------------------------------
CHECK IF DATA IS READY
------------------------------------------------------------

A subject is ready when:

   - data/cache/sub-XXX/anat/sub-XXX_T2w.nii.gz exists and is larger than 1 KB
   - The 2D viewer renders the MRI
   - Spinal cord boundary overlay appears aligned
   - 3D render displays the spinal cord/PAM50/label geometry

------------------------------------------------------------
METRIC TABLES
------------------------------------------------------------

The quantitative metrics panel reads CSV/TSV files under:

   data/metrics/

Recommended columns:

   participant_id, vertebral_level, CSA, FA, MTR

Accepted subject columns:

   participant_id, subject, subject_id, participant, sub

Accepted level columns:

   vertebral_level, level, label, vert_level, disc_level

If no metric files are provided, the app shows an informational empty state.

------------------------------------------------------------
SUMMARY
------------------------------------------------------------

1. Do not push data/ to GitHub.
2. The app downloads MRI and overlay data on demand.
3. The client must provide metric CSV/TSV files for CSA/FA/MTR panels.
4. Use full-resolution mode for anatomy-aware overlays.
5. Use Fast Preview only for quick non-overlay viewing.
