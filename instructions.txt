SPINE MRI VIEWER - CLIENT SETUP & NOTES
=======================================

PROJECT OVERVIEW
----------------
This application is an interactive MRI visualization and analysis tool built using:
- Marimo (interactive notebook UI)
- ipyniivue (MRI volume viewer)
- Python scientific stack (nibabel, numpy, pandas, matplotlib)

It supports:
- MRI visualization (T2-weighted volumes)
- Vendor-based filtering
- Subject selection
- PNG export (MRI slice)
- CSV export (metadata)
- Cohort-level statistical analysis

------------------------------------------------------------

HOW TO RUN THE APPLICATION
------------------------------------------------------------

1. Open project folder

2. Activate virtual environment

3. Install dependencies (if not already installed)

   pip install -r requirements.txt

4. Run the application

   marimo run spine_app.py

5. Open the local URL shown in terminal (browser will launch UI)

------------------------------------------------------------

TESTING (OPTIONAL)
------------------------------------------------------------

Run test suite from project root:

   python -m tests.test_loader
   python -m tests.test_imports
   python -m tests.test_analysis

------------------------------------------------------------

IMPORTANT DATA NOTE (GIT-ANNEX / LARGE MRI FILES)
------------------------------------------------------------

This dataset uses git-annex for storing large MRI files.

WHAT THIS MEANS:
- MRI files (.nii.gz) are NOT always fully downloaded by default
- Some files appear in the dataset but are only placeholders
- Actual image data must be downloaded before visualization

IF IMAGES DO NOT LOAD OR APPEAR EMPTY:

Run the following command for required subjects:

   git annex get data/data-multi-subject/sub-XXX/anat/sub-XXX_T2w.nii.gz

Replace "sub-XXX" with the required subject ID.

WHY THIS IS IMPORTANT:
- Viewer requires full MRI volume data to render slices
- PNG export will fail or produce blank images if data is missing
- Cohort analysis skips missing or incomplete files

------------------------------------------------------------

EXPORT FEATURES
------------------------------------------------------------

1. CSV EXPORT
- Exports subject metadata (subject, vendor, file path)

2. PNG EXPORT
- Exports central axial slice of MRI as PNG image

NOTE:
PNG export only works if the corresponding .nii.gz file is fully downloaded.

------------------------------------------------------------

KNOWN BEHAVIOR / LIMITATIONS
------------------------------------------------------------

- Large MRI files may take time to load
- First-time loading depends on data availability
- Missing files are handled gracefully in the UI
- Performance depends on system memory and dataset size
