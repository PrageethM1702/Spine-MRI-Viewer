------------------------------------------------------------
PROJECT OVERVIEW
------------------------------------------------------------

This application is an interactive spine MRI visualization and analysis tool.

Built with:

   - Marimo
   - IPyNiiVue
   - Plotly
   - nibabel
   - pandas
   - scipy
   - matplotlib

It supports:

   - Vendor filtering
   - Participant selection
   - On-demand MRI download from spine-generic/data-multi-subject
   - 2D multiplanar NIfTI viewing
   - Anatomy-aware 2D overlays
   - Anatomy-aware 3D Plotly visualization
   - Spinal cord boundary overlays
   - Vertebral/disc label overlays
   - PAM50 cord/template proxy overlay
   - Cohort histogram
   - Metadata CSV export
   - 2D slice PNG export
   - 3D Plotly PNG export when kaleido is installed
   - Annotation and screenshot export
   - Distance, Cobb angle, and raw voxel intensity measurement
   - Quantitative metrics CSV/TSV upload and filtering

------------------------------------------------------------
HOW TO RUN LOCALLY
------------------------------------------------------------

From the project root:

   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   marimo run spine_app.py

Open:

   http://localhost:2718

If the browser does not open automatically, copy the URL printed in the terminal.

------------------------------------------------------------
HOW TO RUN IN CODESPACES
------------------------------------------------------------

Open:

   https://codespaces.new/PrageethM1702/Spine-MRI-Viewer

The devcontainer will:

   - Install Python dependencies
   - Install git-annex
   - Create data/cache, data/metrics, and data/data-multi-subject
   - Download participants.tsv
   - Start Marimo on port 2718

------------------------------------------------------------
TESTING CHECKLIST
------------------------------------------------------------

1. Open the app.
2. Select a vendor, for example GE or Siemens.
3. Select a subject.
4. Click Download for that subject.
5. Confirm the 2D viewer loads.
6. Confirm spinal cord boundary overlay aligns in 2D.
7. Switch to 3D render.
8. Confirm spinal cord/PAM50/vertebral label geometry appears.
9. Export metadata CSV.
10. Export 2D slice PNG.
11. Test Plotly 3D PNG export.
12. Use annotation tool and download screenshot.
13. Use ruler, Cobb angle, and intensity probe.
14. Upload a metric CSV/TSV and confirm the metrics panel filters by subject/level.

------------------------------------------------------------
METRIC CSV/TSV REQUIREMENTS
------------------------------------------------------------

The app does not include CSA/FA/MTR metric files by default.

The client should provide metric CSV/TSV files through the app upload widget or
place them in:

   data/metrics/

Recommended columns:

   participant_id, vertebral_level, CSA, FA, MTR

Accepted subject columns:

   participant_id, subject, subject_id, participant, sub

Accepted level columns:

   vertebral_level, level, label, vert_level, disc_level

Example:

   participant_id,vertebral_level,CSA,FA,MTR
   sub-beijingGE01,C1,75.2,0.61,34.5
   sub-beijingGE01,C2,73.8,0.59,35.1

------------------------------------------------------------
PERFORMANCE MODE
------------------------------------------------------------

Full-resolution mode:

   Use this for aligned overlays and final review.

Fast Preview:

   Downsamples large NIfTI volumes for faster viewing.
   Anatomy overlays are disabled in Fast Preview to avoid alignment errors.

------------------------------------------------------------
EXPORT NOTES
------------------------------------------------------------

Metadata CSV:

   Exports subject_id, vendor, field_strength, mean_intensity, and voxel_dims.

2D PNG:

   Exports a central slice fallback image.

3D PNG:

   Exports the Plotly 3D anatomy scene when kaleido is available.
   kaleido is included in requirements.txt.

If 3D PNG export is unavailable:

   pip install -r requirements.txt

Then restart Marimo.

------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------

If the viewer is blank:

   - Make sure the subject was downloaded.
   - Check that git-annex is installed.
   - Try a different subject.

If overlays do not appear:

   - Use full-resolution mode.
   - Click Download again to fetch derivatives.
   - Confirm the subject has matching T2w derivative labels/segmentations.

If metrics panel is empty:

   - Upload metric CSV/TSV files.
   - Confirm subject column matches the active participant ID.
   - Confirm level column uses labels such as C1, C2, T1, etc.

If 3D PNG export is unavailable:

   - Run pip install -r requirements.txt
   - Restart Marimo
